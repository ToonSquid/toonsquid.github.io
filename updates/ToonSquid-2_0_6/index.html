ToonSquid 2.0.6

12 March 2025


ToonSquid 2.0.6 is out now and it comes with many exciting improvements. Here are the most important ones:

Apple Pencil Pro Features

  • Added brush settings to control the brush rotation, size, opacity and wet mix attack with the barrel roll angle of Apple Pencil Pro.
  • Added support for showing the color picker or switching tools with the Apple Pencil Pro squeeze gesture.

Apple Pencil Hover

  • You can now enable the Settings > Tools > Brush > Cursor Hover Preview setting to see the brush outline when hovering over the canvas with Apple Pencil. (Requires a compatible iPad and Apple Pencil model)

Custom Keyboard Shortcuts

  • All keyboard shortcuts under Settings > Keyboard can now be fully customized with your preferred key combinations.

Custom Brush Pressure Curve

  • Go to Settings > Tools > Pressure Curve to customize the pressure response of all brushes when drawing with Apple Pencil.

More Brush Smoothing Options

  • Added more brush smoothing options (Show Gap, Catch Up When Stroke Ends, Adjust With Speed) to the brush settings.
  • Added the ability to override the brush smoothing settings for all brushes at once under Settings > Tools > Brush.

Other

  • You can now enable the Settings > Gestures > Page Flip > Flip Through Drawings Instead Of Frames setting to flip through drawings instead of frames when using the page flip gesture.
  • You can now disable the Settings > Gestures > Select Layers on the Canvas setting to prevent layer selection changes when tapping or dragging on the canvas when the transform tool is selected.
  • The timeline is now automatically scrolled to the selected frame when it is opened for the first time (e.g. after opening the project or after returning from a symbol clip).
  • Switching from the eraser or smudge tool to the pipette tool will afterwards automatically select the brush tool so you can immediately start drawing with the new color.
  • Improved vector fill performance when working with lots of vector stroke brush strokes.
  • Fixed some video playback performance issues.
