ToonSquid 2.0.12

15 September 2025


Multitasking

With this latest update, ToonSquid now supports different window sizes. This includes support for Split View and Slide Over on iPadOS 18 and older, support for Stage Manager and support for the new windowing system in iPadOS 26.
