ToonSquid 2.0.9

12 July 2025


ToonSquid 2.0.9 is here and it comes with one of the most requested features so far:
PSD file support!

PSD Import

If you are an artist who draws their assets in Adobe® Photoshop® or other drawing software that can export PSD files, you can now import your work as a layered PSD file directly into ToonSquid. No more need to export each layer as a separate image and then reassemble them in ToonSquid!

Either import the PSD files into the projects library to automatically create a new project from the PSD, or import them into the current project to insert the PSD layers as drawing layers into your timeline. Supported PSD features include (with certain limitations):

  • Static PSDs
  • Animated PSDs using the frame timeline
  • Animated PSDs using the video timeline
  • Pixel layers
  • Editable text layers
  • Shape layers (vectors)
  • Group layers
  • Smart objects
  • And more!

PSD Export

Not only can you import PSD files, but you can also export your ToonSquid animations as layered PSD files. This is particularly useful for anyone whose professional animation pipeline relies on PSD files, such as for further editing in Adobe® Photoshop® or for sharing with other artists.

Different export modes let you choose between exporting a single frame of your animation as a layered PSD, exporting the entire animation as an animated PSD with a "frame timeline" or a "video timeline", or exporting a sequence of layered PSD files - one for each frame of your animation. Supported PSD features include:

  • Pixel layers
  • Editable text layers
  • Exporting vector layers and path layers as editable shape layers
  • Group layers
  • Exporting symbol layers and animation clips as smart objects
  • And more!

You can learn about the limitations of the PSD export feature here.

Import Settings

  • Use the new Import Images as Symbols setting to control whether imported images should be inserted as a symbol layer or as a pixel layer in the timeline.
  • Use the new Insert Images Into Existing Drawing setting to control whether adding an image to the timeline should always create a new animation layer or not.

Separate Drawings into Animation Layers

  • You can now use the Separate Layers drawing menu action to convert all drawing layers of a drawing into separate animation layers in the timeline.
