ToonSquid 2.0.19

09 February 2026


ToonSquid 2.0.19 contains various improvements and bug fixes:

  • Fixed a regression from the previous update causing brushes to leave temporary marks on the screen while smudging vectors.
  • Improved the video playback behaviour to avoid video clips visibly popping in.
  • Reduced the likelihood of accidental brush strokes when trying to pinch to zoom the canvas while finger drawing is enabled.
  • Fixed certain cases that caused exported PSDs not to open correctly in Photoshop.
  • If a project gets corrupted for whatever reason, instead of disappearing from the project library, it will now continue to show up as a placeholder with options to try to restore it from a backup file, export the corrupted project file for inspection or delete it.
