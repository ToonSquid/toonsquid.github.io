ToonSquid 2.0.22

16 May 2026


With ToonSquid 2.0.22 you can now use a liquify tool for pixel layers and import static and animated WebP files into your project.

Liquify#

The liquify tool has been one of the most requested features for ToonSquid and it's finally here! With a pixel layer selected, select the Smudge tool and enable its new Liquify mode to warp the pixels in your layer with one of six different liquify modes.

Push

Twirl

Pinch

Expand

Reconstruct

Filter

Intensity

WebP Import#

Many static and animated images that you download from the internet are in the WebP file format. Now you can import those files directly into ToonSquid without having to convert them to a different file format first.

Other Improvements#

  • Use the new Anti-Aliasing Mode export setting to force high quality anti-aliasing to be applied to every frame of your animation. This can significantly improve the visual quality of downscaled images in your animation.
  • Various other bug fixes and reliability improvements.
