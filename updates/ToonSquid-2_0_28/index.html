ToonSquid 2.0.28

30 October 2026


ToonSquid 2.0.28 introduces workflow improvements when working with the mesh effect, a list view in the library, a Japanese localization, new keyboard shortcut options and various other improvements.

Smudge Mesh Tool#

Use the new Smudge Mesh Tool to shift multiple mesh control points at once.

Draw Mesh#

Instead of tapping to place individual mesh control points with the Add Mesh Tool, you can now drag to place multiple control points. Tap on the "Add Mesh" tool button again to customize the point spacing.

Generate Mesh#

Tap on the "Add Mesh" tool button again to use the option to automatically generate a mesh over your layer contents.

Library List View#

You can now switch the projects library and the project asset library into a list view for easier viewing of long names and for easier editing of deep folder hierarchies.

Japanese Localization#

The ToonSquid UI is now fully available in Japanese. If Japanese is set as the primary language on your iPad, but you prefer to continue to use the English ToonSquid UI, go to the iPad Settings app > Apps > ToonSquid and change the Language to English.

Many thanks to all native Japanese speakers who provided feedback on the translation during beta testing!

New Keyboard Shortcut Options#

The following actions can now be assigned custom keyboard shortcuts:

  • adding layers
  • locking and unlocking layers
  • changing layer visibilities
  • toggling effects
  • toggling onion skins
  • toggling looped playback

Other Improvements#

  • Added reset buttons to the "General", "Tools", "Import", "Gestures" and "Backup" settings tabs.
  • Removed the layer visibility check for various timeline edits so that retiming, drag and drop etc. can now be performed on hidden animation layers.
  • The "Single Frame", "Frame Timeline" and "PSD Sequence" PSD export modes now support the loop setting of group layers in the timeline.
  • Fixed the contents of hidden pixel layers in the PSD export with a camera layer not to be empty.
  • Fixed hidden empty animation layers not to appear in exported PSDs as group layers unless the "Always Export Animation Layers As Groups" export setting is enabled.
  • Fixed the missing localizations of the "Lock", "Duplicate" and "Delete" options when swiping a layer to the left in the layer list.
  • Added localizations for the default color palettes.
  • Fixed number inputs when the decimal format preference on the device does not use . as the decimal separator.
  • Fixed mesh and warp effects on group layers to always prevent child layers from being directly controlled by bones of the bones effect at the same time.
  • Fixed a mesh effect rendering issue that sometimes caused unwanted jittering.
  • Added a workaround for an iPadOS bug to prevent microphone input gain changes in other apps potentially affecting audio recording in ToonSquid.
  • Fixed the merging of drawing layers onto a pixel layer not to cut off any of the lower layer contents when the layers are inside of a group or transform hierarchy with a scale other than 1.
  • Fixed a bug in the behaviour of copying and pasting keyframes of multiple layers at once.
  • Fixed a bug when editing easing curves of effects placed on animation layers when the selected drawing does not start on frame 1.
  • Fixed unwanted frame changes when trying to tap on playhead to bring up the keyframe actions on empty frames.
  • Fixed empty frames of animation layers not to be exported as PSD layer when the animation layer has an effect to be rasterized.
  • Various other stability improvements.
