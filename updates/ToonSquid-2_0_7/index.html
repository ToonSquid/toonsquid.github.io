ToonSquid 2.0.7

08 April 2025


With ToonSquid 2.0.7 it is now easier to work with audio in your projects than ever before.

Audio Recording

Record audio directly in ToonSquid using the new audio recording feature. Tap the + button in the timeline, select Audio, then select Record.

Import Videos as Audio Only

It is now possible to select videos from either the Files or the Photos app when importing audio into your timeline. This will automatically extract and only import the audio of the selected video.
