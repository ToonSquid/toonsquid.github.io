ToonSquid 2.0.25

29 July 2026


ToonSquid's latest update includes numerous keyframing workflow improvements and a noticeable step-up in the shape assist accuracy for curves, ellipses and polylines.

Stretch Keyframes#

You can now proportionally scale the timing of a selection of keyframes.

Reverse Keyframes#

You can now reverse a selection of keyframes. This also automatically reverses their respective easing curves.

Easing Step#

The new Step setting for easing curves lets you define the rate at which keyframes should be interpolated.

Only Show Properties With Keyframes#

ToonSquid can now automatically hide all layer properties from the timeline that don't contain any keyframes.

Edit Keyframes in Multiple Layers#

You can now perform keyframes edits such as drag and drop, copy and paste, deletion, insertion, stretching etc. for a selection of keyframes that spans across multiple animation layers.

Edit Multiple Keyframe Properties#

You can now edit multi-selections of animatable layer properties at once without the other properties getting deselected automatically when bringing up the actions menu.

Keyframe Umbrella Row Visibility#

Previously, the keyframe umbrella row was only shown if a layer had any effects. Now you can choose for this row to always be shown in the timeline, letting you quickly select and edit all properties of a layer in the timeline.

Custom Keyframe Drag Delay#

You can now customize the duration for which you have to touch and hold on a selection of keyframes before you can drag them to a different frame in the timeline. The default duration has also been lowered slightly for a more responsive out-of-box experience.

You can find this setting under Settings > Gestures > Keyframes > Drag and Drop Hold Delay.

Other Improvements#

  • Improved Shape Assist accuracy for ellipses, curves and polylines.
  • The keyframe selection now remains intact after dragging and dropping keyframes to a different frame.
  • Fixed an issue that could sometimes prevent projects from being duplicated.
  • Fixed an issue that could sometimes prevent project backups from being imported.
  • Fixed the liquify tool to respect the "Drawing Assist" setting of the drawing guides.
  • Fixed an issue that could sometimes cause crackling audio.
  • Fixed the transform tool's flip behaviour when the parent hierarchy of a layer is also flipped.
  • Fixed a bug that could cause a brush's dual brush settings to be lost when imported under rare circumstances.
  • Various other bug fixes and reliability improvements.
